# mattermost-desktop — Arch Linux package

Packaging for [Mattermost Desktop](https://github.com/mattermost/desktop) 6.4.0,
the Electron desktop client for Mattermost.

## Fork provenance

Forked from the Arch Linux package **mattermost-desktop**:

<https://archlinux.org/packages/extra/x86_64/mattermost-desktop/>
<https://gitlab.archlinux.org/archlinux/packaging/packages/mattermost-desktop>

Originally packaged and maintained by **Caleb Maclennan** <caleb@alerque.com>
and **Bruno Pagani** <archange@archlinux.org>, with contributions from
**Raphael Nestler**, **William Gathoye**, **Aleksandar Trifunović**, **Jan Was**,
**AUR[Severus]** and **Matthias Mailänder**. Many thanks to them, and to the
Mattermost developers for the upstream project.

This fork is maintained by **Miroslav Pavleski** <miroslav@pavleski.net> and is
published through the [ArchPackages pacman repository](https://archpackages.github.io/archrepo/).

Build with `makepkg -f`; install with `pacman -U`.
